# Référence de marque embarquée dans le kit

Lire ces deux fichiers avant de produire ou de réviser un livrable client :

1. `01-RSPIR-ESSENCE-DE-MARQUE.md`;
2. `02-RSPIR-SYSTEME-VISUEL-PREMIUM.md`.

Ils gouvernent le ton et la présentation, mais ne changent jamais le sens de l'offre, la preuve disponible ni la portée du Diagnostic.

Ne jamais inventer un symbole RSPIR. Tant que l'emblème n'est pas verrouillé, utiliser le wordmark.
