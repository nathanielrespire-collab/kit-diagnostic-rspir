# Test officiel de la garantie

À exécuter après la session de décision.

| Critère | Satisfait | Preuve | Limite | Retour requis |
|---|---|---|---|---|
| Direction | non | | | |
| Justification | non | | | |
| Preuve | non | | | |
| Conditions | non | | | |
| Économie | non | | | |
| Séquence | non | | | |
| Action | non | | | |

Une décision de mesurer avant d'investir peut satisfaire la garantie. Si l'analyse RSPIR est insuffisante, retourner à l'étape précise concernée.

Ne jamais garantir rendement, économie, revenu, subvention, implantation, adoption, tiers ou délai futur dépendant du client.
