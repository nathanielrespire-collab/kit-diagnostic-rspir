# Paquet de convergence

Hypothèse V1 : rencontre d'environ 30 minutes.

## À présenter

- ce que la lecture commence à révéler;
- les zones significatives;
- les priorités candidates comparées;
- le périmètre qui semble passer en premier;
- pourquoi il passe devant;
- l'information qui pourrait encore l'invalider;
- ce que RSPIR propose d'approfondir;
- ce qui ne sera pas approfondi maintenant.

- Périmètre validé :
- Dimensions reliées :
- Résultat visé :
- Frontières :
- Décideurs présents :
- Réserves :
- Mesure supplémentaire, si nécessaire :
- Preuve de validation :

L'analyse verticale ne commence pas sans cette décision.
