# RSPIR — SYSTÈME VISUEL PREMIUM

## Principe
Le système visuel doit donner l’impression d’un cabinet qui comprend profondément les organisations et qui n’a pas besoin de surjouer sa compétence.

Le luxe vient de :
- l’espace;
- la retenue;
- la précision;
- les proportions;
- la typographie;
- la qualité des transitions;
- la cohérence.

Pas des effets.

---

# Palette

## 1. Forêt — couleur d’autorité
**#183128**

Usage :
- grands fonds;
- header sombre;
- CTA principaux;
- sections de méthode;
- graphiques structurants.

Rôle :
stabilité, profondeur, maîtrise.

## 2. Encre — couleur de texte
**#17221D**

Usage :
- titres;
- texte fort;
- lignes importantes.

Rôle :
éviter le noir pur et conserver la chaleur de la marque.

## 3. Papier — fond principal
**#F5F1E8**

Usage :
- fond général;
- grandes respirations;
- sections éditoriales.

Rôle :
matière, calme, lumière naturelle.

## 4. Ivoire — surface élevée
**#FBF9F4**

Usage :
- cartes;
- dossiers;
- panneaux;
- modules de contenu.

## 5. Pierre — structure secondaire
**#D8D3C8**

Usage :
- séparateurs;
- bordures;
- éléments inactifs;
- grilles.

## 6. Sauge grisée — information secondaire
**#85938A**

Usage :
- texte secondaire;
- diagrammes;
- labels.

## 7. Cuivre / écorce — accent rare
**#A36F43**

Usage :
- repères;
- numérotation;
- nœuds;
- petits accents;
- états actifs.

Règle :
moins de 5 % de la surface visuelle.

Le cuivre doit signaler. Jamais décorer gratuitement.

---

# Agencement des couleurs

## Pages claires
Papier + Encre.

Le blanc pur est rare.

Les cartes sont Ivoire.

Les bordures sont Pierre.

Le cuivre apparaît comme ponctuation.

## Pages sombres
Forêt + Papier.

Les lignes deviennent des blancs très transparents.

Le cuivre peut être légèrement plus lumineux.

## Rythme
Le site alterne :
- lumière;
- concentration;
- lumière;
- concentration.

Les sections sombres doivent apparaître aux moments où le visiteur entre dans la méthode ou dans une idée structurante.

# Typographie

## Titres
Style éditorial serif.

Stack recommandée :
**Iowan Old Style, Baskerville, Georgia, serif**

Caractéristiques :
- grandes tailles;
- poids modéré;
- peu de gras;
- interligne serré;
- largeur contrôlée.

Rôle :
intelligence, recul, autorité calme.

## Sous-titres et corps
Style néo-grotesk précis.

Stack :
**Inter, Helvetica Neue, Arial, sans-serif**

Rôle :
lisibilité, modernité, système.

## Labels
Sans-serif, très petit, capitales espacées.

Usage :
- numéros;
- étapes;
- catégories;
- micro-navigation.

Ne pas surutiliser le monospace.

# Hiérarchie

## H1

Toujours une idée forte.

Jamais plus de 2–3 lignes sur desktop.

## H2
38–58 px.

Une idée par section.

## H3
24–32 px.

Utilisé pour nommer une décision, une étape ou une composante.

## Body
16–18 px.

Largeur maximale :
60–66 caractères.

Interligne :
1.6–1.75.

## Microtexte
10–12 px.

Labels, catégories, notes.

# Logo

## Principe
Le site ne doit pas dépendre d’un symbole non encore totalement verrouillé.

Le **wordmark RSPIR** est suffisant comme ancrage principal.

Le symbole futur peut enrichir la marque, mais ne doit pas sauver le design.

## Traitement recommandé
- mot RSPIR calme;
- espacement légèrement augmenté;
- aucun effet;
- taille raisonnable;
- beaucoup d’espace autour.

## Emblème
La piste organique doit rester compatible avec :
- nature;
- mouvement;
- respiration;
- croissance;
- R latent;
- silhouette simple.

Tant que l’emblème n’est pas final, ne pas inventer un faux symbole dans le site.

---

# Graphiques

Les graphiques RSPIR doivent ressembler à des **cartes de décision**, pas à des dashboards SaaS.

Éléments :
- lignes fines;
- nœuds;
- relations;
- étapes;
- convergence;
- couches;
- trajectoires.

Éviter :
- bar charts décoratifs;
- gradients techno;
- heatmaps inutiles;
- fausse data;
- gros chiffres sans contexte.

---

# Iconographie

Minimaliste.

Priorité :
- traits simples;
- géométrie douce;
- aucune illustration 3D;
- aucun robot;
- aucune puce électronique cliché.

Quand un texte suffit, ne pas ajouter d’icône.

---

# Photographie

Quand utilisée :
- vrais humains;
- lumière naturelle;
- textures sobres;
- environnement réel;
- profondeur;
- peu de mise en scène.

Portraits :
calmes, éditoriaux, directs.

Pas de posture « startup founder ».

---

# Règle finale

Si un élément visuel attire plus l’attention que l’idée qu’il doit expliquer, il est probablement trop fort.
