# Contrôleurs du Diagnostic

Chaque contrôle retourne `reussi`, `a corriger` ou `bloquant`, avec les fichiers et éléments visés.

## 1. Anti-invention

- [ ] chaque chiffre porte une source et une date;
- [ ] chaque inconnue reste visible;
- [ ] les déclarations ne sont pas présentées comme observations;
- [ ] les hypothèses importantes portent un niveau de confiance;
- [ ] aucune valeur plausible ne remplit un vide.

## 2. Pertinence et effort client

- [ ] chaque demande peut changer le périmètre ou la décision;
- [ ] seules des pièces existantes sont demandées;
- [ ] RSPIR absorbe la reconstruction;
- [ ] aucune collecte « au cas où »;
- [ ] le dirigeant demeure dans la cible d'effort à mesurer.

## 3. Radar D01–D31

- [ ] les 31 dimensions ont servi de radar;
- [ ] aucune analyse détaillée automatique des 31;
- [ ] aucune moyenne de maturité;
- [ ] seules les candidates passent les cinq filtres;
- [ ] un seul périmètre vertical standard est approfondi.

## 4. Preuve et contradictions

- [ ] les sources sont récupérables;
- [ ] faits, observations, déclarations, hypothèses et recommandations sont séparés;
- [ ] les preuves contraires sont visibles;
- [ ] les contradictions matérielles sont résolues ou assumées;
- [ ] les chaînes causales distinguent symptôme et cause.

## 5. Priorisation et convergence

- [ ] les cinq filtres sont appliqués;
- [ ] les poids officiels sont utilisés;
- [ ] le score ne remplace pas le jugement;
- [ ] les alternatives principales sont comparées;
- [ ] ce qui peut invalider le périmètre est nommé;
- [ ] le périmètre est validé avant l'analyse verticale.

## 6. Portée

- [ ] toute information supplémentaire peut encore changer la décision;
- [ ] architecture, configuration, migration, POC et implantation sont séparés;
- [ ] un second périmètre n'est pas absorbé gratuitement;
- [ ] les modules conditionnels restent proportionnels;
- [ ] le Diagnostic garde une valeur autonome.

## 7. Cas économique

- [ ] le niveau A, B ou C correspond aux données;
- [ ] hypothèses, fourchettes et confiance sont explicites;
- [ ] le coût de l'inaction n'est utilisé que s'il est défendable;
- [ ] aucun rendement spectaculaire n'est fabriqué;
- [ ] la recommandation peut être de ne pas investir.

## 8. Second regard

- [ ] priorité, cause, économie, portée et recommandation sont challengées;
- [ ] chaque réserve importante reçoit une réponse;
- [ ] aucune réserve ne disparaît par reformulation;
- [ ] les limites assumées apparaissent dans le Dossier.

## 9. Dossier et portabilité

- [ ] les douze sections sont présentes;
- [ ] les neuf questions de valeur reçoivent une réponse;
- [ ] la Stop List est présente;
- [ ] la prochaine décision est précise;
- [ ] un tiers compétent peut comprendre sans RSPIR;
- [ ] aucun contenu interne confidentiel n'est exposé.

## 10. Garantie et fermeture

- [ ] la session de décision a précédé le test officiel;
- [ ] les sept critères sont satisfaits;
- [ ] une insuffisance RSPIR retourne à l'étape concernée;
- [ ] une incertitude valide précise quoi mesurer avant quelle décision;
- [ ] le suivi d'appropriation a eu lieu;
- [ ] la phase suivante est distincte.
